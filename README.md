# LivingBrush, reports notebook

Public working notebook for the LivingBrush website
(https://www.livingbrush.com). One short dated report per work session, in
`reports/`, newest first in [reports/INDEX.md](reports/INDEX.md).

The Project Manager reads this through raw.githubusercontent.com and cannot
list folders, so every report is added to INDEX.md in the same commit that
adds the report.

Public-folder rules: no passwords or keys, no server names, no client names,
and no number that was not actually measured.
